Modular Architecture

        
How rea-image Works

        
An 8-stage deterministic pipeline executing offline mathematics before falling back to heuristics or optional multi-modal LLM sanity checks.

      


      

        

          Stage M1
          
Ingest & Normalization

          
Transposes EXIF orientations (tags 1–8), normalizes ICC color spaces, and calculates SHA-256 and perceptual hashes.

        


        

          Stage M2
          
Region Decomposition

          
Spatial segmentation (SLIC/Watershed + Tesseract OCR text merging) produces binary masks and crops in layers/.

        


        

          Stage M3
          
Forensic Engines

          
C2PA Content Credentials, EXIF hardware tags, PNG metadata, Poisson noise correlation, 2D FFT spectral peaks, and DCT grid alignment.

        


        

          Stage M4
          
Craft Deconstruction

          
Classifies 12 lighting setups, camera lens apertures, focal lengths, 5–6 color palette roles, and typography hierarchies.

        


        

          Stage M5
          
Judge & Conflicts

          
Bayesian evidence ledger weights provenance > forensics > visuals. Emits needs_review if contradictory signals emerge.

        


        

          Stage M6
          
Recreation Router

          
Identifies cheapest viable path: prompts for AI, shoot plans for photography, Blender scripts for 3D, SVG/HTML for graphic design.

        


        

          Stage M7
          
Output Bundle

          
Exports verdict.txt, machine-readable report.json, and the self-contained interactive report.html.

        


        

          Stage M8
          
Series Consistency

          
Multi-image folder mode cross-audits ad carousels for uniform aspect ratio, dominant medium, and color palette continuity.

        

      

    


    
    

      

        
Taxonomy

        
The 7 Production Methods Detected

        
Images rarely fit into a binary 'real vs fake' toggle. rea-image isolates true production mechanisms per region.

      


      

        

          📷
          
Real Photograph

          
Captured by a physical camera sensor with optical depth of field, natural frequency falloff, and Poisson-distributed sensor noise.

          
    
            
  • Signals: Poisson noise (r > 0.35), natural 1/f^α falloff (α ~ 2.0), camera EXIF, 8x8 DCT grid alignment.
    • 
          

        


        

          🤖
          
AI-Generated

          
Synthesized via diffusion models or GANs, exhibiting periodic convolution peaks, generator chunk metadata, or watermarks.

          
    
            
  • Signals: 2D FFT spectral peaks (transposed conv artifacts), A1111/ComfyUI/Invoke metadata, standard bucket resolutions (1024x1024, 896x1152).
    • 
          

        


        

          🧊
          
3D Render

          
Modeled and ray-traced in software like Blender, Maya, Unreal Engine, or Cinema4D with procedural PBR shader falloffs.

          
    
            
  • Signals: Perfect geometric vertex planar facets, procedural noise texturing, pristine raytraced reflections, export software tags.
    • 
          

        


        

          📐
          
Vector / Graphic Design

          
Digital layouts created in Illustrator, Figma, or Canva, marked by exact color runs, sharp vector boundaries, and zero sensor noise.

          
    
            
  • Signals: High flat-run coverage (>35%), low color entropy (<0.03 unique ratio), near-zero noise (p75 < 0.8), minimal ELA error.
    • 
          

        


        

          🖥️
          
UI / Screenshot

          
Direct captures of application screens or web interfaces, featuring pixel-grid aligned rectangular cards, buttons, and system fonts.

          
    
            
  • Signals: Axis-aligned edge histograms (>60%), resampled flat runs across UI cards, clean text blocks, standard display resolutions.
    • 
          

        


        

          🎨
          
Illustration / Painting

          
Traditional or digital artwork drawn by artists, showing expressive brush strokes, stylized lighting, and intentional color palettes.

          
    
            
  • Signals: Multi-scale edge gradients, non-photographic chromatic variance, stylized high-contrast outline boundaries.
    • 
          

        


        

          ✂️
          
Composite / Spliced

          
Multi-layered compositions combining photographs, 3D renders, or text graphics where forensic noise and lighting properties diverge.

          
    
            
  • Signals: Variance in quadrant noise levels (>3.0x), conflicting DCT quantization grids, mismatch between regional verdicts.
    •

Quick Setup

        
Install In Seconds

        
Compatible with Python 3.10 through 3.14 on Linux, macOS, and Windows.

      


      

        
1. Standard Installation

        
pip install git+https://github.com/Ibrahist/rea-image.git


        
2. Optional Extras (OCR, HEIC, AVIF, VLM)

        
# Install with full OCR, Apple HEIC, and AVIF decoding
pip install "rea-image[ocr,heic,avif]"

# Or install for local development
git clone https://github.com/Ibrahist/rea-image.git
cd rea-image
pip install -e ".[dev,ocr]"


        
3. Run Your First Analysis

        
rea-image analyze ./my_image.png --open

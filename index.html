Pipeline Flow

        
The 8 Modular Stages

        
Executing deterministic offline mathematics before falling back to heuristics or optional multi-modal LLM sanity checks.

      


      

        

          Stage M1
          
Ingest & Normalization

          
Transposes EXIF orientation tags 1–8, normalizes ICC color profiles, and computes SHA-256 and perceptual hashes.

        


        

          Stage M2
          
Region Decomposition

          
Spatial SLIC & Watershed segmentation combined with Tesseract OCR merges text blocks and UI cards into layers/.

        


        

          Stage M3
          
Forensic Engine

          
Inspects C2PA Content Credentials, EXIF hardware tags, Poisson noise correlation, 2D FFT spectral peaks, and DCT 8x8 alignment.

        


        

          Stage M4
          
Craft Deconstruction

          
Classifies illumination into 12 standard lighting rigs, estimates camera lens aperture and focal length, and extracts 5–6 color roles.

        


        

          Stage M5
          
Judge & Conflicts

          
Bayesian evidence ledger strictly weights Provenance > Forensics > Visuals. Emits needs_review when signals clash.

        


        

          Stage M6
          
Recreation Router

          
Dispatches cheapest viable path: layered prompts for AI, shoot plans for photos, Blender 4.x scripts for 3D, SVG/HTML for graphic design.

        


        

          Stage M7
          
Output Bundle

          
Exports single-line summary verdict.txt, machine-readable report.json, and self-contained interactive report.html.

        


        

          Stage M8
          
Series Consistency

          
Batch folder mode audits multi-slide carousel ads and social campaigns for uniform aspect ratios, color grading, and style cohesion.

        

      

    


    
    

      

        
Taxonomy

        
The 7 Production Methods

        
Images rarely fit into a simplistic binary label. rea-image isolates true production mechanisms per spatial region.

      


      

        

          📷
          
Real Photograph

          
Captured by an optical camera sensor with natural frequency falloff, Poisson-distributed sensor noise, and hardware EXIF data.

          
    
            
  • Key Signals: Poisson noise (r > 0.35), natural 1/f^α falloff (α ~ 2.0), camera EXIF, 8x8 DCT grid alignment.
    • 
          

        


        

          🤖
          
AI-Generated

          
Synthesized via latent diffusion or GAN models, showing periodic convolution spikes, generator metadata chunks, or watermarks.

          
    
            
  • Key Signals: 2D FFT spectral peaks, A1111/ComfyUI parameters, standard bucket resolutions (1024x1024, 896x1152).
    • 
          

        


        

          🧊
          
3D Render

          
Modeled and ray-traced in software like Blender, Maya, Unreal Engine, or Cinema4D with procedural PBR shader falloffs.

          
    
            
  • Key Signals: Geometric vertex planar facets, procedural noise texturing, pristine raytraced reflections, export software tags.
    • 
          

        


        

          📐
          
Vector / Graphic Design

          
Digital layouts created in Illustrator, Figma, or Canva, marked by exact color runs, sharp vector boundaries, and zero sensor noise.

          
    
            
  • Key Signals: High flat-run coverage (>35%), low color entropy (<0.03 unique ratio), near-zero noise (p75 < 0.8), minimal ELA error.
    • 
          

        


        

          🖥️
          
UI / Screenshot

          
Direct captures of application screens or web interfaces, featuring pixel-grid aligned rectangular cards, buttons, and system fonts.

          
    
            
  • Key Signals: Axis-aligned edge histograms (>60%), resampled flat runs across UI cards, clean text blocks, standard display resolutions.
    • 
          

        


        

          🎨
          
Illustration / Painting

          
Traditional or digital artwork drawn by artists, showing expressive brush strokes, stylized lighting, and intentional color palettes.

          
    
            
  • Key Signals: Multi-scale edge gradients, non-photographic chromatic variance, stylized high-contrast outline boundaries.
    • 
          

        


        

          ✂️
          
Composite / Spliced

          
Multi-layered compositions combining photographs, 3D renders, or text graphics where forensic noise and lighting properties diverge.

          
    
            
  • Key Signals: Variance in quadrant noise levels (>3.0x), conflicting DCT quantization grids, mismatch between regional verdicts.
    •

Practical Utility

        
Where This Tool Is Used

        
Connecting creative professionals, engineers, and investigators with actionable blueprints.

      


      

        

          
🎨 Designers & Art Directors

          
Layered Prompts • Palette Roles • scaffold.svg

          
Deconstruct moodboards, extract color roles (background, subject, accent), and convert graphic posters into clean vector SVGs without manual tracing.

ASCII Lighting Diagram • Gear List • shoot_plan.md

          
Reverse-engineer client reference photos into concrete studio setups (e.g. Butterfly, Rembrandt, Softbox) with camera ISO, aperture, and lighting ratios.

Transform design mockups and UI screenshots directly into responsive CSS components, extracting spacing, font candidates, and color tokens.

        


        

          
🧊 3D & Game Artists

          
Blender Cycles Scene • PBR Shaders • starter_scene.py

          
Replicate architectural rendering lighting rigs, camera lens settings, and studio key/fill lights with executable Blender 4.x Python scripts.

        


        

          
🔍 Trust, Safety & Journalism

          
C2PA Manifests • ELA • verdict.txt • report.json

          
Detect synthetic media and image tampering with cryptographically signed C2PA verification, sensor Poisson noise, and JPEG double-compression checks.

        


        

          
📈 Marketing Teams

          
consistency_summary.json • Batch Carousel Audits

          
Audit multi-slide carousel ads and product catalogs in batch mode to ensure uniform aspect ratios, consistent color grading, and coherent brand styling.

Quick Setup

        
Install In Seconds

        
Compatible with Python 3.10 through 3.14 on Linux, macOS, and Windows.

      


      

        
1. Standard Installation

        

          pip install git+https://github.com/Ibrahist/rea-image.git
          
        


        
2. Optional Extras (OCR, HEIC, AVIF)

        

          pip install "rea-image[ocr,heic,avif]"
          
        


        
3. Run Your First Analysis

        

          rea-image analyze ./my_image.png --open
